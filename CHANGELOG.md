# Changelog

## 0.2.0

- Add context-scoped recollections, disputes, retractions and historical source
  validation with distinct provenance-preserving graph layers.
- Add reusable participant profiles, directory filters and facets, deterministic
  portraits and responsive reconstruction screen composition.
- Add audited profile corrections, visibility and reversible identity merges;
  enforce canonical identity when recording and managing claims.
- Add configured isolated practice sessions and terminal confirmation/input
  handling, with detached SQLite read caching and changed-history validation.
- Add the optional terminal extension, CLI and standalone rehearsal world.
- Extract shared viewport, keyboard, navigation, inspectors, matrix geometry and
  network rendering. The host retains its existing gameplay workflows and saves.
- Add read-only actor-bound action discovery with disabled decision reasons.
- Default to two-column matrix cells with three detail levels and configurable
  network background rendering.

## 0.1.0

- Extract the UI-independent collective model, action and policy evaluation,
  ordered event history, replay and neutral projections from Saddle Pathways.
- Add scoped simulation submissions, portable world and history schemas,
  explicitly hypothetical branches and in-memory and SQLite stores.
- Include a fictional consumer covering an inferred match, attendance,
  negotiation, approval, fulfilment and independent verification.
- Preserve the legacy host transaction and storage formats.
